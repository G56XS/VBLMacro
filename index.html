AKARI and ENCHO each keep their own shiftlock state, timing, and override — so tuning one never touches the other.

Built like a real dashboard, not a script window

Everything runs through a live glass UI with telemetry, not a console you have to squint at.

Roblox focus lock

Input only fires while Roblox is the actual foreground window — checked by executable, window class, and title, so nothing leaks into other apps.

Typing Mode

One key pauses every macro hotkey so you can chat normally, then resumes exactly where you left off.

Custom keybinds

Rebind combo, override, shiftlock toggle, and mode switch — validated against conflicts before saving.

Per-profile timing

Step delay, jump delay, and shiftlock-to-dash delay are tunable separately for all four profiles.

Session telemetry

Live fire count, last action, uptime, and an 80-entry activity console for every mode switch and combo.
